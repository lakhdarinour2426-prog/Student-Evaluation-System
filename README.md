Student Evaluation and Specialization Ranking System

Project Description

This project is a web-based system designed to evaluate students and rank university specializations using the Weighted Sum Model (WSM).

Objectives

- Manage student information.
- Manage academic specializations.
- Define evaluation criteria and weights.
- Record student evaluations.
- Calculate specialization scores.
- Rank specializations automatically.
- Recommend the best specialization for each student.

Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

Methodology

The system uses the Weighted Sum Model (WSM) to calculate weighted scores and determine the best specialization for each student.

Installation

1. Install XAMPP.
2. Copy the project folder into "htdocs".
3. Start Apache and MySQL.
4. Create the project database using phpMyAdmin.
5. Import the database SQL file.
6. Open the project in your browser.
